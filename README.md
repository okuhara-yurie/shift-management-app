
# まなびシフト
### 個別指導塾向け勤怠・シフト管理Webアプリ

## 1．概要

本アプリは，個別指導塾の室長が行う授業配置や講師の勤怠管理などの業務負担を軽減することを目的として，Google Apps Script（GAS）を用いて試作したWebアプリです．

当日の授業配置，講師の勤務状況，確認が必要な事項などを一つの画面で把握できる仕組みを目指しています．

通常授業は固定シフトをもとに管理し，代講・振替・講習などの変更が発生した場合には，必要な部分だけを修正できる構成としています．

現在は試作段階であり，機能の実装や動作確認，改善を進めています．

## 2．開発背景

個別指導塾では，一人の室長が授業運営，保護者対応，講師のシフト調整，勤怠確認など，幅広い業務を担当しています．

また，通常授業に加えて，講師の欠勤や生徒の予定変更による代講・振替，長期休暇中の講習などが発生するため，授業配置の管理が複雑になりやすいという特徴があります．

これらの情報を紙や複数の表計算ファイルで管理している場合，必要な情報を確認するために複数の資料を見比べる必要があり，変更の反映漏れや確認作業の負担につながります．

そこで，授業配置と勤怠情報を一元管理し，室長が必要な情報を短時間で確認できるアプリを開発しようと考えました．

## 3．解決したい課題

主に以下の課題の解決を目指しています．

- 当日の授業配置を確認するために時間がかかる
- 固定シフトを繰り返し入力する必要がある
- 代講・振替・講習などの変更が反映されない可能性がある
- 講師の打刻漏れや未出勤の確認に手間がかかる
- 講師や生徒の重複登録などの入力ミスを発見しにくい
- 複数の資料に情報が分散しており，必要な情報を探しにくい

## 5．主な機能

### 5.1 当日のシフト表示

講師名を縦軸，授業時間を横軸とした時間軸形式で，当日の授業配置を確認できる画面を設計しました．

講師一人が同じ時間帯に最大二人の生徒を担当する個別指導塾の特徴を考慮しています．

また，通常授業・振替授業・講習を色分けし，授業区分を視覚的に把握できる仕組みを目指しています．

### 5.2 固定シフトと日別変更

曜日・時間・講師・生徒の組合せが決まっている通常授業は，固定シフトとして管理します．

代講や振替などが発生した場合には，変更が必要な部分だけを日別シフトとして編集する構成としています．

これにより，通常授業を毎回入力する負担を減らし，変更内容を管理しやすくすることを目指しています．

### 5.3 勤怠管理

講師の出勤・退勤・休憩の打刻を管理する機能です．

講師が簡単に打刻できることに加え，管理者が勤務状況をまとめて確認できる仕組みを目指しています．

### 5.4 管理者画面

室長が授業配置や勤怠状況を確認するための管理者画面を設けています．

打刻漏れ，未出勤，担当講師の未設定，シフトの重複など，確認が必要な事項をまとめて把握できる仕組みを目指しています．

### 5.5 振替・講習の管理

通常授業に加え，振替授業や講習を区別して管理する仕組みです．

生徒ごとに授業区分を管理し，申込コマ数や実施済みコマ数，残コマ数などを確認できる機能を目指しています．

※各機能には開発途中のものも含まれています．

## 6．開発時に工夫した点

### 6.1 実際の業務を想定した機能設計

個別指導塾では，講師一人が同じ時間帯に二人の生徒を担当する場合があります．

そのため，講師単位だけでなく生徒単位で授業区分を管理できるようにすることを意識しました．

例えば，同じ講師が担当する二人の生徒のうち，一人は通常授業，もう一人は振替授業という場合にも対応できる構成を考えました．

### 6.2 入力作業を減らすための設計

毎週繰り返される通常授業は固定シフトとして管理し，変更が発生した部分だけを日別に編集する方法を採用しました．

これにより，同じ授業情報を繰り返し入力する必要を減らし，管理者の作業負担を軽減することを目指しました．

### 6.3 必要な情報を一画面に集約

授業配置や勤怠状況などの情報を複数の画面や資料で確認するのではなく，管理者が確認すべき情報をまとめて把握できる構成を意識しました．

特に，未出勤や打刻漏れなど，対応が必要な情報を優先的に表示することで，確認漏れを防ぐことを目指しています．

### 6.4 機能ごとのプログラム分割

プログラムを機能ごとにファイル分割し，処理の役割を整理しました．

画面表示，シフト管理，勤怠管理，管理者機能，データの読み書きなどを分けることで，機能の追加や修正を行いやすい構成を意識しています．
